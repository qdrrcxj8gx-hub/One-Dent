# One Dent

Статический сайт на HTML, CSS и JavaScript. Сборка и установка пакетов не нужны: откройте index.html в браузере или через Live Server.

## Что работает

- Адаптивная верстка, мобильное меню, доступные с клавиатуры диалоги услуг и FAQ.
- Шесть филиалов: выбор синхронизирует форму, контакты, телефон, WhatsApp и ссылку на 2ГИС.
- Форма готовит сообщение в WhatsApp выбранного филиала. Посетитель отправляет его сам; запись подтверждает администратор. Сервер, CRM, хранение заявок и отправка писем не подключены.
- Карта — схематичная иллюстрация со ссылкой на точную карточку выбранного филиала в 2ГИС.
- Фотографии хранятся локально. Manrope загружается из Google Fonts; при недоступности сети используется Arial.

## Файлы

index.html — структура и тексты; style.css — оформление; script.js — интерактивность и массив branches с контактами; assets/ — изображения и favicon.

## Расширение: врачи и контекст филиала

Добавлены 15 специалистов с фотографиями, поиск по имени/специальности, фильтр направлений, режимы «В выбранном филиале» и «Вся сеть». Запись к врачу добавляет ФИО в сообщение; при выборе врача другого филиала адрес переключается на опубликованное место приёма. При смене филиала несовместимый выбранный врач сбрасывается.

Переключатель сверху обновляет телефон, рейтинг и ссылки на отзывы, особенности диагностики, условия входа, маршрут, список врачей, форму и метаданные страницы. Выбор адреса сохраняется в localStorage (`onedent-branch`); имя и переписка не сохраняются. Запросы записей по-прежнему не отправляются автоматически.
